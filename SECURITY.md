# Security policy

SmokeRoom is a local comparison tool. It does not ship credentials, and it
does not accept a modeled concentration as a safety decision.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository:

https://github.com/Harry0052/smokeroom/security/advisories/new

Please include the version or commit, the fixture or input shape that
triggers the issue, and the effect you observed. Do not include monitoring
data that you are not allowed to share, and do not open a public issue for
an unfixed vulnerability.

There is no bug-bounty program and no supported production deployment.
