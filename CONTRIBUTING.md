# Contributing

Issues and pull requests are welcome on this repository.

- Run `ruff check src tests scripts` and `pytest` from a virtual environment
  created with the README install.
- Keep new trials synthetic unless the pull request also records calibration,
  redistribution permission, collection dates, and station metadata.
- Do not add credentials, access tokens, or personal contact details.
- A modeled concentration must stay a comparison result, not a safety rating.
